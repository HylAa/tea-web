# TeaHvh API代理服务器实施计划

## 🎯 项目目标
将客户端直接访问API改为通过Node.js代理服务器访问，添加Redis缓存层，防止直接访问受限的API。

## 📋 需求分析
- **核心需求**: 阻止客户端直接访问 `https://api.teahvh.cc/api`
- **技术方案**: Node.js + Express + Redis缓存
- **缓存策略**: 
  - 排行榜：24小时缓存
  - 服务器列表：1分钟缓存
  - 其他接口：根据业务特性设置

## 🏗️ 架构设计

### 系统架构
```
客户端(Vue) --> Node.js代理服务器 --> Redis缓存
                       |
                       v
               https://api.teahvh.cc/api
```

### 技术栈
- **后端服务**: Node.js + Express
- **缓存系统**: Redis (使用ioredis库)
- **HTTP客户端**: Axios
- **进程管理**: PM2
- **安全防护**: Helmet + CORS + 速率限制
- **日志系统**: Winston

## 📊 缓存策略详情

| API路径 | 缓存时间 | 说明 |
|---------|----------|------|
| `/levelrank/*` | 24小时 | 排行榜数据更新频率低 |
| `/servers` | 1分钟 | 服务器列表需要相对实时 |
| `/server/*` | 1分钟 | 单个服务器状态实时性要求高 |
| `/announcement/*` | 10分钟 | 公告信息中等更新频率 |
| `/user/*` | 不缓存 | 用户数据需要实时同步 |

## 🔒 安全措施

## 🚀 部署方案

### 开发环境
1. 启动Redis服务
2. 运行 `npm run dev`
3. 前端配置API地址为 `http://localhost:3001/api`

### 生产环境
**方案1: PM2部署**
```bash
npm install
pm2 start pm2.config.js --env production
```

**方案2: Docker部署**
```bash
docker-compose up -d
```
